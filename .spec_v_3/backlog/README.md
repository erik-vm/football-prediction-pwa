# Backlog

Tickets are created here by the Orchestrator after the planning phase.

## File Naming
- `TICKET-001.md`, `TICKET-002.md`, etc.
- Sequential numbering
- Use `templates/TICKET-template.md` format

## Priority Order
- P0 tickets first (critical path)
- P1 tickets second (important)
- P2 tickets last (enhancements)

## Dependency Rules
- A ticket cannot start until all its dependencies are DONE
- Orchestrator tracks dependencies and assigns work accordingly

## Status Tracking
- Each ticket file contains its own status
- Orchestrator maintains overall progress view
